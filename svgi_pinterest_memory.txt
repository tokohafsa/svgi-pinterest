## STACK
- Framework: Streamlit (deployed ke Streamlit Cloud)

- Frame extraction: imageio-ffmpeg (bundle binary)
- Storage: Dropbox API (App Folder: /Apps/SVGI Pinterest/)
- Output: CSV + video tersimpan ke folder session di Dropbox

## PIPELINE FLOW — TAB 1 (Instagram)
1. New Session → buat folder Dropbox: /2026-07-29_1430
2. Paste URL Instagram reel/post (support carousel dengan ?img_index=N)
3. Fetch metadata (yt-dlp) + download video
4. Upload video ke Dropbox
5. Extract frames thumbnail detik 1 sampai max 30 (ffmpeg)
6. Preview video + thumbnail grid (klik untuk pilih, border merah tanda terpilih)
7. Raw caption ditampilkan (read-only)
8. Credits: field Poster @ + @Mentions dari caption (auto-detect, editable)
   Preview credit line realtime di bawah field
9. Input pin name + pilih Board + pilih Sector
10. Generate → review/edit Title, Description, Keywords
11. Regenerate jika perlu
12. Add to Queue → Link = cur["ig_url"] (URL post asli)
13. Loop ke step 2 untuk URL baru
14. Generate CSV Preview → Edit CSV → Upload ke Dropbox (3 step terpisah)

## PIPELINE FLOW — TAB 2 (Direct URL / GIF)
1. Paste direct URL (.mp4 / .mov / .gif)
2. Download file + extract frames thumbnail
3. Preview video + thumbnail grid
4. Input manual: Nama pin, Credit animator (plain text), Link ke konten asli (per pin)
5. Pilih Board + Sector
6. Generate → review/edit Title, Description, Keywords
7. Add to Queue → Link = source_link yang diinput manual
8. Generate CSV Preview → Edit CSV → Upload ke Dropbox (3 step terpisah)

Catatan:
- GIF: download → convert ke MP4 via ffmpeg → upload Dropbox → Video URL = Dropbox link
- MP4/MOV: download untuk thumbnail saja → Video URL = direct URL (tidak upload Dropbox)
- Link per pin bersifat manual dan unik, bukan global affiliate link

## CAROUSEL FIX (instagram.py)
- _parse_img_index(url): parse ?img_index=N dari URL (1-based)
- _strip_img_index(url): buang parameter sebelum kirim ke yt-dlp
- yt-dlp fetch seluruh carousel dengan ignoreerrors=True (tidak crash kalau ada foto)
- _pick_entry(info, img_index): filter entries yang video (cek formats, vcodec, ext),
  lalu ambil entry ke-N sesuai img_index (1-based)
- Fallback: kalau tidak bisa filter, pakai index mentah dari entries

## FORMAT TITLE
{Nama} {suffix board}. {CTA_TITLE}

Suffix per board (BOARD_TITLE_SUFFIX di model.py):
- Logo Animations             → "Logo Animation"
- E Sports Gaming ...         → "Logo Animation"
- Famous Brand ...            → "Logo Animation"
- Brand Identity in Motion    → "Animated Brand Identity"

Contoh board biasa:    "Vortex Logo Animation. See bio link 🔗"
Contoh Brand Identity: "Nike Animated Brand Identity. Bio link 🔗"

## CTA TITLE — A/B TEST OTOMATIS (_fit_cta_for_title)
Pinterest limit title = 100 chars. CTA title dipisah dari CTA description.
Fungsi pure Python, tidak pakai Groq.

CTA_TITLE_VARIANTS (14 varian, max ~20 chars):
"See our bio link 🔗", "Check our bio link ✨", "Tap the bio link 🎬",
"Bio link 🔗", "Visit our bio link 💡", "Link in bio 🎯", dll.

Logika _fit_cta_for_title(pin_title, preferred_cta, max_len=100):
1. Coba preferred_cta (CTA_TITLE_VARIANTS[cta_index])
2. Coba semua CTA_TITLE_VARIANTS secara berurutan, ambil yang pertama fit
3. Fallback ke varian terpendek, truncate di batas kata kalau masih tidak fit

## CTA DESCRIPTION (CTA_VARIANTS)
14 rotasi soft-sell, dipakai di baris terakhir description.
Index = cta_index % 14, berbeda dari index title.
Contoh: "Inspired by this? Our bio link connects you with the right motion designer 🔗"

## FORMAT DESCRIPTION
Line 1: {credit_line}
Line 2-3: seo_body (2 kalimat SEO natural, max 200 chars)
Line 4: {cta_desc dari CTA_VARIANTS}

Catatan:
- Title TIDAK diulang di baris pertama description
- Jangan sebut 3D, three-dimensional
- Board "Brand Identity in Motion": seo_body bicara tentang brand system
  dan visual identity, BUKAN logo reveal atau logo intro
